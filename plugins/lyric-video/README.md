# lyric-video

Команда `/lyric-video <текст песни>` (алиас `/lyric-edit`) отправляет Claude задачу собрать вертикальный лирик-эдит: MP4 1080×1920, 30 fps, без звука. Вместе с текстом уходит памятка `brief.md`: подпись капсом по словам (~110 мс) с цветными плашками, своя SVG-сцена на каждую строку, спокойный фон по настроению трека, «качание» на 120 BPM с припева, рендер через playwright с подменой таймеров и ffmpeg (crf 17–18), проверка по контактному листу. Чтобы поменять правила, отредактируйте `brief.md`.
