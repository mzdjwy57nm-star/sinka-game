# Scene recipes (tested)

Each recipe = app screen + what moves + payoff. Pick by the meaning of the line; never reuse one in the same video.

| Lyric theme | Screen | Motion / payoff |
|---|---|---|
| She writes, he is silent | Chat from HIS phone: her grey bubbles on the left | typing dots → message, header "печатает…", blue ticks + "прочитано тобой", he types "прости" and deletes it |
| Someone ignores / not delivered | Composer typing, red "!" | "не доставлено", strength bar drops |
| A large number / "где-то сто" | 10×10 grid filling + counter | reaches 100 → RGB glitch + "ПЕРЕГРУЗКА" |
| Heart stops / ending | Heart + ECG monitor, BPM | heart pulses with QRS, "пик" per beat → flatline turns red, BPM to 0, heart greys, "пи-и-и-и", stamp "СТОП" |
| "Помни / remember / love letter" | Envelope | flies in, wax heart seal cracks, flap opens, letter zooms, text handwritten (Lora italic, clip reveal + pen dot), heart drawn by stroke, falling petals |
| Memories / repeat of a line | Polaroids dropping | captions "мы", "лето", "помни"; older ones fade to grey (overlay, not opacity) |
| Breakup / "не хочет быть со мной" | Shared photo | tears along a zigzag, her half drifts away, chip |
| "Only me" / favourite | Her chat list | my chat rises to the top, gets pinned, hearts float, others dim |
| "Not in her plans" | Week calendar | fills with events, my block tries to drop in, hits, shakes, drifts away |
| Hard but keep going | Night street | figure with backpack walks in rain, lamps and puddles scroll, step counter, progress "до дома" |
| Insult / verdict | Rating stars | 5 → 1 star, typed word, stamp "ВЕРДИКТ" |
| What she thinks | Thought cloud | word swaps, intelligence bar drops |
| Drink / mixing | Recipe app | glass fills from two streams, sliders 50/50 |
| Place ("под мостом") | Night map | bridge, river ripples, pin with pulse — no body |
| Trend / "модно" | Trends list | line climbs to #1 with flame |
| Lazy / idle | To-do list | unchecked boxes, figure hands in pockets, "0 / 12" |
| Tears heal | Bowl filling with drops | splash rings, healing bar |
| "Look at me" | Eye with moving pupil | call rings, accept/decline buttons |
| "Heal my wounds" | Heart with plaster | healing ring 0→100% |
| Warmth / winter | Thermostat, tea, snow | gauge rises, steam, snowflakes melt |
| Longing / "скучал" | Map with two pins or call log | distance shrinks / missed calls counter |
